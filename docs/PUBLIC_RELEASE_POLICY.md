# Public Release Policy

この文書は、公開リポジトリに含める情報の範囲を定義します。

## 公開するもの

- 変換対象と対応範囲
- CLIの基本利用方法
- テスト方針
- スナップショット検証の考え方
- 実コーパスをリポジトリ外で管理する方針

## READMEで薄くするもの

- 実測カバレッジの詳細数値（詳細は `docs/coverage-report.md`）
- 実コーパス運用の具体導線
- 実案件運用を連想させる細部（閾値の内部背景、運用フローの詳細）

## 非公開寄りで扱うもの

- 実案件由来コーパスの運用手順詳細
- 実コーパス評価基準の詳細
- 精度改善ヒューリスティクスの内部ノウハウ
- 実運用向けの内部連携情報

## 運用ルール

- READMEは「何ができるか / 使い方 / 安全方針」を中心に保つ
- 詳細実測は docs に分離
- 実コーパスは常にリポジトリ外で管理
